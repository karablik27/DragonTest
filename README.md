## DragonTest - iOS приложение - превращает процесс обучения в увлекательную игру с драконами 

DragonTest делает обучение увлекательным: каждый пройденный тест — это новый шаг к завоеванию драконов и формированию собственной коллекции.

### Архитектура

- **Клиент** (iOS):

1. UIKit + RealityKit (3D драконы, анимации)
2. Архитектурный подход MVP + сервисы.
3. Асинхронное взаимодействие (async/await)
4. Кэширование моделей драконов

- **Сервер** (Firebase / Firestore):
  
1. Хранение пользователей, тестов, вопросов, результатов и много другого
2. Реальное время синхронизации данных
3. Авторизация через FirebaseAuth

### Реализовано
1. Реализована регистрация/авторизация студентов и преподавателей
2. Реализован запуск тестирования
3. Полностью реализовано прохождение теста
4. Ручная проверка реализована полностью (студент может увидеть оценку за тест и фидбек)
5. Реализована автоматизированная проверка ответов с помощью ИИ

### Фичи
1. Не разрешено делать скриншот при прохождении теста
2. Не разрешено вставка и копирование текста
3. Анимация с двигающимся драконом
4. Вибрация при старте теста для полного погружения в процесс
5. Возмозность коллекционирование драконов
6. Уведомления при добавлении теста и при проверке теста
